# 관리 화면 공통 컴포넌트 규칙

관리 화면(캐릭터 관리·컨텐츠 설정 등, `app/views/admin/`)은 **같은 종류의 요소를 같은 컴포넌트 하나로** 만든다.
입력칸은 입력칸 컴포넌트, 날짜는 날짜 입력칸, 모달은 모달 컴포넌트를 그대로 다시 쓴다.
화면마다 새 클래스·새 마크업을 만들지 않는다. 필요한 모양이 없으면 **컴포넌트를 먼저 만들고 이 문서에 적은 뒤** 쓴다.

- 마크업: `app/views/admin/ui/_*.html.haml`
- 모양: `app/javascript/styles/mastodon/_admin_ui.scss` (`ui-*` 클래스)
- 동작: `app/javascript/entrypoints/admin.tsx` (모달 열고 닫기, 팝오버 위치, 아이템 고르기)

## 컴포넌트 목록

| 컴포넌트 | 파일 | 쓰는 곳 |
|---|---|---|
| 소제목 묶음 | `admin/ui/_section` | 화면의 한 덩어리 (프로필 설정처럼 소제목 + 내용). 오른쪽 버튼(추가·지급 등)은 `actions` |
| 입력칸 줄 | `admin/ui/_fields` | 입력칸 여러 개를 한 줄에. `columns: 2/3` 로 칸 수 고정, 없으면 자동 |
| 입력칸 | `admin/ui/_field` | 글·숫자·날짜·색·드롭다운·여러 줄 글. `type:` 으로 고른다 |
| 스위치 | `admin/ui/_switch` | 켜기/끄기 |
| 고르기 (바로 저장) | `admin/ui/_segmented` | 둘 이상 중 하나, 누르면 바로 저장 (점수제/판수제, 기숙사/진영) |
| 고르기 (폼 안) | `admin/ui/_choice` | 둘 이상 중 하나, 폼과 함께 보냄 (지급: 재화/아이템). 모양은 `_segmented` 와 같다 |
| 여러 개 고르기 | `admin/ui/_multi_select` | 체크 목록 드롭다운 (캐릭터 여러 명 등) |
| 아이템 고르기 | `admin/ui/_item_picker` | 아이템마다 개수를 정해 여러 개 (인벤토리 카드 모양) |
| 탭 안의 탭 | `admin/ui/_subtabs` | 탭 아래 두 번째 줄 탭 (수업 > 설정·과목들). `items: [[이름, 주소, 지금?, 꺼짐?]]` |
| 모달 | `admin/ui/_modal` | 입력창 팝업. `data-modal-open="id"` 버튼으로 연다 |
| 모달 버튼 줄 | `admin/ui/_modal_actions` | 모달 폼 맨 아래 [취소] [저장] |

## 쓰는 법

### 소제목 묶음 + 입력칸

```haml
- add = button_tag safe_join([material_symbol('add'), '시즌 추가']), type: :button, class: 'button', data: { modal_open: 'season-add' }
= render layout: 'admin/ui/section', locals: { title: '시즌', hint: '안내 한 줄 (없어도 됨)', actions: add } do
  = render layout: 'admin/ui/fields', locals: { columns: 2 } do
    = render 'admin/ui/field', label: '시작일', name: 'game_season[starts_on]', value: season.starts_on, type: :date
    = render 'admin/ui/field', label: '종료일', name: 'game_season[ends_on]', value: season.ends_on, type: :date
```

### 입력칸 `type`

| type | 칸 | 더 받는 값 |
|---|---|---|
| `:text` (기본) | 한 줄 글 | `placeholder`, `html: { maxlength: }` |
| `:number` | 숫자 (step 1) | `html: { min:, max: }` |
| `:date` | 날짜 | |
| `:color` | 색 고르기 | |
| `:select` | 드롭다운 | `options: [[보이는 이름, 값]]`, `include_blank:` |
| `:textarea` | 여러 줄 (한 줄 전체) | `html: { rows: }` |
| `:custom` | 직접 넣기 | `render layout:` 블록 안에 칸을 넣는다. 칸에는 `class: 'ui-input ui-input--<종류>'` |

공통: `label`(필수), `name`, `value`, `id`(없으면 name 으로 만든다), `hint`, `required`, `wide`(한 줄 전체), `data`·`extra`(감싸는 칸에 붙일 data 속성·클래스).

### 모달

```haml
= button_tag '추가', type: :button, class: 'button', data: { modal_open: 'house-add' }

= render layout: 'admin/ui/modal', locals: { id: 'house-add', title: '기숙사 추가' } do
  = form_tag admin_game_houses_path, method: :post, class: 'simple_form' do
    = render 'admin/ui/field', label: '이름', name: 'game_house[name]', required: true, wide: true
    = render 'admin/ui/modal_actions', submit: '추가'
```

- 저장하다 오류가 나면 컨트롤러가 `?modal=<id>` 로 돌려보내 모달을 다시 열어 둔다.
- 모달 안 드롭다운·팝오버는 모달에 잘리지 않게 화면 기준으로 띄운다 (아래 공간이 모자라면 위로).

### 고르기

```haml
-# 바로 저장
= render 'admin/ui/segmented', url: scoring_admin_game_houses_path, param: :scoring_mode, value: @scoring_mode,
                               options: [['점수제', 'points'], ['판수제', 'games']]
-# 폼 안에서
= render 'admin/ui/choice', name: 'give_kind', value: 'money', options: [['재화', 'money'], ['아이템', 'items']]
```

### 여러 개 고르기 · 아이템 고르기

```haml
= render 'admin/ui/multi_select', name: 'character_ids[]', placeholder: '캐릭터 고르기', all_label: '전체 선택',
                                  options: characters.map { |c| [c.display_name, c.id] }

-# 보내는 값: items[][name], items[][count]
= render 'admin/ui/item_picker', name: 'items', options: GameShopItem.order(:name).map { |item| [item.name, 그림 주소 또는 nil] }
```

## 지킬 것

1. 입력칸은 `admin/ui/_field` 로만 만든다. `.input.with_label` 를 화면에서 직접 쓰지 않는다 (simple_form `f.input` 도 새로 쓰지 않는다).
2. 날짜는 `type: :date`, 색은 `type: :color`, 숫자는 `type: :number`. 글자칸으로 날짜·숫자를 받지 않는다.
3. 팝업 입력창은 `admin/ui/_modal` + 맨 아래 `admin/ui/_modal_actions`. 새 `<dialog>` 를 만들지 않는다.
4. 화면의 덩어리는 `admin/ui/_section` (소제목 + 내용). 접었다 펴는 `<details>` 묶음은 새로 만들지 않는다.
5. 드롭다운 목록은 모달·표 밖으로 나와 보여야 한다: 단일 선택은 `<select>`(community_select.ts 가 띄움), 여러 개는 `_multi_select`, 아이템은 `_item_picker`.
6. 아이콘(`material_symbol`)은 `app/javascript/material-icons/400-24px/` 에 있는 이름만 쓴다 (없으면 그림이 크게 깨진다).
7. 버튼: 주 동작 `button`, 보조 `button button-secondary`, 약한 동작 `button button-tertiary`, 아이콘만 `icon-button`.
8. 표는 `.bot-sheet-table.game-table > table.table` 그대로 쓴다.
9. 새 컴포넌트를 만들면 위 목록 표와 쓰는 법에 적는다.
