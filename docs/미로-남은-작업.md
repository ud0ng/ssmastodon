# 트라이위저드 미로 개편: 남은 작업 (2026-10-26)

미로(`Game::Web::Maze`, 웹 전용 이벤트)를 새 규칙과 새 무대 화면으로 바꾸는 중이다.
진행 중인 작업을 `5c2f446` 으로 먼저 커밋했다.
이 문서는 그 커밋의 코드를 읽고 정리한 것이라, 작업하던 쪽의 계획과 다를 수 있다. 다르면 이 문서를 고친다.

## 지금 된 것

- **서버 규칙** (`app/lib/game/web/maze.rb`, 맨 위 주석이 전체 규칙)
  - 인원별 미로 세 단계 (최대 턴 25·30·40)

    | 인원 | 크기 | 입구 | 가짜 우승컵 |
    |---|---|---|---|
    | 2~4명 | 15×15 | 각자 다른 입구 | 0개 |
    | 5~10명 | 21×21 | 4곳 | 1개 |
    | 11~24명 | 27×27 | 8곳 | 2개 |

  - 개인전 / 기숙사 팀전 (`team_mode`). 팀은 최대 6명이고 팀원끼리 지도를 함께 쓴다.
  - 동시 이동 (1~2칸). 함정은 1턴 정지다.
  - 마법 생물: 힌트를 보고 통하는 주문을 고른다. 틀리면 2턴 정지.
  - 아이템: 포인트 미, 루모스 (시야 +1, 3턴).
  - 조우 단계 (30초): 몰래 협력·방해를 고른다. 협력하면 지도를 나누고, 방해받으면 1턴 정지에 적대 표시가 붙는다.
  - 가짜 우승컵(포트키 함정): 잡으면 무작위 입구로 날아간다.
  - 붉은 불꽃: 기권.
  - 순위: 우승컵 → 최단 거리 순. 팀전은 팀 점수로 정한다.
- **새 무대 화면**: `features/system/maze_stage.tsx` (`MazeStage`). `session.tsx` 가 진행·끝난 미로 방에서 이것을 띄운다.
- **그림**: `features/system/maze_art.ts`. game-icons.net 아이콘으로 CC BY 3.0 이고 출처는 파일 맨 위에 있다.
- **정리**: 예전 화면 `maze.tsx`(`MazePlay`)는 지웠고, `board.tsx` 에서 미로 부분을 뺐다.
- **확인한 것**
  - `spec/lib/game/maze_spec.rb`, `spec/requests/api/v1/system/web_commands_spec.rb`: 12개 통과
  - TypeScript 검사: 통과

## 남은 일

1. **무대 스타일이 없다 (가장 먼저)**
   - `maze_stage.tsx` 의 `mz-*` 클래스(78개) 스타일이 아직 없어서 지금은 화면이 꾸며지지 않은 채로 나온다.
   - `app/javascript/styles/mastodon/_game_maze.scss` 를 새로 만들고, `_game_marauders.scss` 처럼 불러오는 곳에 넣는다.
   - 예전 미로 스타일이 남아 있으면 정리한다: `components.scss` 의 `&--maze`, `.maze-play__svg` 등.
2. **규칙 안내(가이드)가 예전 규칙 그대로다**
   - `app/lib/game/guide.rb` 의 `'maze'` 에 아직 예전 규칙이 적혀 있다: 생물·적대 주문 대결(공격 > 무장해제 > 방어), 포트키 아이템, 4명.
   - 새 규칙으로 고칠 것: 생물별 주문, 포인트 미·루모스, 가짜 우승컵, 붉은 불꽃, 조우 30초, 팀전, 인원별 미로.
   - `stage_tutorial.tsx` 의 미로 안내 단계와 그림(`DEMOS`)도 같이 맞춘다.
3. **도입부**
   - 도둑 지도처럼 카운트다운 → 오프닝 → 지도 → 역할·조작 안내 순서로 할지 정한다.
   - 지금은 `session.tsx` 의 `StageTutorial`(미로) 이 진행 화면과 함께 뜬다.
4. **알림·효과**
   - 도둑 지도에서 한 것처럼 할지 정한다: 효과음, 소리 버튼, 장소별 소식, 내 차례 안내, 채팅 배지.
   - 미로에서 효과를 줄 장면: 함정, 생물 조우, 아이템 줍기, 가짜 우승컵 순간이동, 우승.
5. **미리보기에서 끝까지 해 보기**
   - 인원 세 단계(3·8·16명 정도)
   - 팀전 켜기
   - 조우 30초 타이머와 기본값(고르지 않으면 협력)
   - 생물 주문 실패 시 2턴 정지
   - 가짜 우승컵
   - 기권
   - 결과·보상·소속 점수 (테스트 플레이는 점수·보상 없음)
6. **관리 화면**
   - 컨텐츠 설정 > 미로의 새 항목이 제자리에 묶여 보이는지 확인한다 (`team_mode`, `steps`, `vision`, `turn_seconds`, `encounter_seconds`, `first_turn_bonus`, 함정·생물·아이템 비율, 루모스, 생물 정지 턴, 명령어들).
   - 이벤트 인원 2~24명이 설정과 맞는지 확인한다.
7. **부하**
   - 24명 판에서 `/view` 요청 쿼리 수와 시간을 확인한다. CLAUDE.md 의 '이벤트·컨텐츠 서버 부하 줄이기' 기준은 200ms 아래이고, 참가자는 `Lobby.preload_characters` 로 미리 읽어야 한다.
8. **문서**
   - CLAUDE.md 의 컨텐츠 설명에 새 미로 규칙과 화면 파일을 적는다. 끝나면 이 문서는 지운다.

## 주의
