## 끝난 것

- **서버 규칙** (`app/lib/game/web/maze.rb`, 맨 위 주석에 전체 규칙)
  - 인원별 미로 크기·입구·가짜 우승컵·최대 턴

    | 인원 | 크기 | 입구 | 가짜 우승컵 | 최대 턴 |
    |---|---|---|---|---|
    | 2~4명 | 15×15 | 각자 다른 입구 | 0개 | 25 |
    | 5~10명 | 21×21 | 4곳 | 1개 | 30 |
    | 11~24명 | 27×27 | 8곳 | 2개 | 40 |

  - 동시 이동, 함정
  - 마법 생물: 힌트를 보고 주문을 고른다
  - 아이템: 포인트 미, 루모스
  - 조우: 협력·방해, 적대 표시
  - 가짜 우승컵 포트키, 붉은 불꽃(기권)
  - 거리 순위, 기숙사 팀전
- **점수·보상**: 미로에서 따로 만들지 않고 공통 처리(`finish!`)로 끝낸다. 그래서 테스트 플레이에는 점수가 없고, 하루 보상 제한도 다른 컨텐츠와 똑같이 적용된다.
- **테스트**
  - 미로 테스트를 새 규칙에 맞게 다시 썼다 (`spec/lib/game/maze_spec.rb`).
  - 컨텐츠·시스템 API 테스트 279개를 돌렸고, 실패한 1개는 고쳐서 다시 통과시켰다. 고친 뒤 전체를 한 번 더 돌리지는 못했다.
  - 커밋할 때 `maze_spec.rb`·`web_commands_spec.rb` 12개와 TypeScript 검사는 다시 통과를 확인했다.

  - 불의 잔 오프닝, 규칙 안내
  - 조우 클로즈업, 생물 주문
  - 포트키 소용돌이, 하늘이 열리는 폭죽

  - 예전 미로 화면 `maze.tsx` 는 지웠고, `board.tsx` 에서도 미로 부분을 뺐다.
  - 아이콘 그림 `maze_art.ts` 를 추가했다. game-icons.net, CC BY 3.0, 출처는 파일 맨 위에 있다.

## 정해 둔 것 (바꾸려면 말하기)

- 기숙사 팀전은 대기실에서 고르지 않고, 컨텐츠 설정의 "기숙사 팀전"(`team_mode`)을 켜서 정한다.
- 팀전에서 한 기숙사가 6명을 넘으면 두 팀으로 나눈다.
- 같은 사람과는 3턴이 지나야 다시 조우한다. 함께 걸을 때 매 턴 조우가 뜨지 않게 하려는 것이다.
- 최대 턴이 지나면 무승부로 하고, 거리 순위만 보여 준다.

## 함께 확인할 것 (코드를 읽다가 보인 것)

- **규칙 안내 문구가 예전 규칙 그대로다.** `app/lib/game/guide.rb` 의 `'maze'` 에 생물·적대 주문 대결(공격 > 무장해제 > 방어), 포트키 아이템, 4명 같은 예전 내용이 남아 있다. 새 화면의 규칙 안내가 이것을 쓰는지 보고 새 규칙으로 맞춘다. `stage_tutorial.tsx` 의 미로 안내도 마찬가지다.
- **도입부가 겹치는지 본다.** `session.tsx` 의 `StageTutorial`(미로) 이 새 오프닝·규칙 안내와 겹쳐 뜨는지 확인한다. 도둑 지도는 카운트다운 → 오프닝 → 지도 → 안내 순서로 바꿨고, 안내가 겹쳐서 진행 방법 창을 뺐다.
- **관리 화면.** 컨텐츠 설정 > 미로에 새 항목(`team_mode`, `steps`, `vision`, `turn_seconds`, `encounter_seconds`, `first_turn_bonus`, 함정·생물·아이템 비율, 루모스, 생물 정지 턴, 명령어들)이 제자리에 묶여 보이는지, 이벤트 인원 2~24명이 맞는지 본다.
- **부하.** 24명 판에서 `/view` 요청의 쿼리 수와 시간을 본다. CLAUDE.md 의 '이벤트·컨텐츠 서버 부하 줄이기' 기준(200ms 아래, 참가자 미리 읽기)을 따른다.
- **문서.** 끝나면 CLAUDE.md 의 컨텐츠 설명에 새 미로 규칙과 화면 파일을 적고, 이 문서는 지운다.
